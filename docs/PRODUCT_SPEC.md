# S3S 产品规格

S3S 面向在 Windows、macOS 或 Linux 上管理对象存储的用户。用户可以在一个桌面窗口切换多个云账号、浏览对象、传输大文件，并在关机后继续传输。本文描述目标行为。各项能力的实现与验证进度见 [STATUS.md](STATUS.md)。

## 工作区与账号

- 账号管理显示名称、厂商、端点及区域。添加或编辑账号时，在同一表单填写公开配置和可选的访问凭据。表单应提供各厂商的填写示例，并标明当前可用的云操作。首批厂商为 AWS S3、Cloudflare R2、阿里云 OSS、火山引擎 TOS，同时保留手动配置通用 S3 兼容端点的入口。各连接有独立身份，切换视图不取消该账号已入队的任务。
- 按厂商能力展示桶、前缀和分页对象列表。继续翻页要使用与当前账号、桶及查询条件匹配的游标。区分加载中、空桶、权限不足、离线和未接入等状态。
- 对象标识由连接、桶和完整 Key 组成。Key 中的前导斜杠、相邻斜杠、点段、空格、百分号和 Unicode 均原样保存。界面可以按前缀展示层次。下载目标的本地路径须单独选择、验证，并限制在目标目录内。
- 常用操作包括上传、下载、查看对象信息、复制和删除。没有底层支持的操作须明确标注。复制后删除所实现的移动需要分别追踪两步结果，删除和覆盖应让用户能识别目标。
- 正常模式只显示持久化记录和真实请求结果。示例内容只允许出现于明确的 Demo 模式或测试夹具。M0 不需要云账号即可打开所有页面。

## 传输、恢复与限速

Go 引擎拥有队列、调度、分片、重试、进度和校验的生命周期。界面发出命令并观察状态。文件字节在 Go 和云 SDK 之间流动。多个账号、多个文件、并行分片、重试和测速共用同一套引擎。

1. 上传和下载都应先持久化可定位任务的身份、本地路径、方向、源版本和目标。中断后能解释已确认字节、剩余工作和等待用户处理的条件。
2. 分片上传保存远端会话 ID、分片边界、已确认结果与校验信息。恢复时与厂商的服务端状态核对。下载只复用已经写入并验证、且仍对应同一源对象的区间。
3. 断网、正常退出、进程崩溃和电脑重启均属于恢复场景。源文件替换、远端对象变更、会话过期或权限变更需要可解释的恢复决策。取消任务应清理未完成会话及临时资源，并记录清理失败。
4. 发起完成请求和最终持久化之间也可能崩溃。引擎须核实最终对象状态后才能标为成功。按云 API 语义解释 ETag、版本和校验和，特别考虑分片与加密对象。
5. 提供全速、办公、自定义三种模式。分别配置每秒上传和下载的总字节数。总量覆盖整个应用，不能因账号数、并发分片数或重试次数增加而倍增。更改限额、切换页面或切换语言时继续既有任务。

## 测速与 R2 连接优化

测速由用户指定连接和桶，向专用唯一 Key 上传真实数据，复用正式传输与限速路径。开始前显示时间和流量上限。到达任一上限后停止发送，记录耗时、实际发送字节和结果，再删除测试对象并终止未完成分片。失败或异常退出后仍应能定位待清理资源。

R2 支持对少量候选 IP 实测、手动指定、缓存过期和连接失败后回退到常规解析。覆盖范围仅为该 R2 端点实际建连的目标 IP。请求 URL、HTTP Host、TLS SNI、证书校验和签名均保留原始端点域名。不同账号、端点与重定向目标需要分别匹配。诊断界面应说明选用路径和回退结果。

## 语言、凭据与诊断

- 所有产品可见文本来自独立语言资源，包括导航、状态、错误、按钮、无障碍标签及应用创建的原生菜单、托盘、通知。内置简体中文和美式英语。新增语言可导入，只缺个别条目时逐项回退。占位符在各语言中同名，允许次序不同。
- 语言切换作用于展示，包括对已有错误的重新解释。任务和分片持久化采用稳定标识。语言和视图生命周期不得拥有或重建传输引擎。
- 错误返回稳定码、参数、厂商原始错误码、请求标识和可重试性，可关联重试历史。中文版需提供能指导用户判断或处理的解释。导出诊断前脱敏令牌、签名、认证头、临时凭据及 URL 查询中的敏感信息。
- 凭据由受支持的安全存储保管，连接配置可引用凭据。源码、前端持久化、日志、截图、测试快照和诊断导出均不得保存凭据。普通 PR 验证独立于真实云账号和发布权限。
