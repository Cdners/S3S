# 路线图与验收

每个阶段依赖前一阶段可复现的工程和检查。阶段验收需要当次提交的证据；当前进度及其限制见 [STATUS.md](STATUS.md)。

| 阶段 | 交付范围 | 完成标准 |
| --- | --- | --- |
| M0 | Go 核心边界、SQLite 初始迁移和持久化、双语 Wails 工作区、原生跨平台构建 | 连接、对象、任务、设置四页可到达，未接入功能有真实提示；语言 key 和参数一致，切换与回退可验证；实际数据库重开可读回任务和分片；PR 与 main 对应提交在四个原生目标构建，产物可下载。桌面交互、编译与产物下载分别记录证据。 |
| M1 | AWS S3、Cloudflare R2 的多账号、桶和对象分页、上传下载及常用操作；持久队列与可靠恢复 | 两家真实测试桶完成操作矩阵和字节校验；已确认的分片和下载区间经断网、退出、终止进程、重启后核对并续传；恢复冲突、取消、失败和清理有可读结果。 |
| M2 | 阿里云 OSS、火山引擎 TOS；统一能力模型和厂商差异处理 | 评估并分别固定原生 SDK；四家执行同一操作及中断矩阵，逐项标出不支持项、厂商错误和请求标识；分别验证列表、分片、校验和终止会话语义。 |
| M3 | 应用级聚合限速、真实上传测速和 R2 建连优化 | 多账号并发及重试共享每方向预算；对指定桶的测速受时间和流量双重约束并完成清理；候选与手动 IP、过期、失败回退均有证据，原始 Host、SNI、签名和证书校验仍有效。 |
| M4 | 安装包、签名及测试版本发布 | 在声明支持的 Windows、macOS 和 Linux 系统上从发布候选产物完成安装、启动、更新或迁移、传输恢复与卸载验收；记录签名、校验和、平台要求和已知限制，再人工批准测试发布。 |

开发过程中可分批合入阶段内的改动。只编译通过的目标记录为“构建通过”；真实云联调、重启和安装验收各有独立结果。rclone 可用于兼容性和性能对比，恢复验收依据始终是 S3S 自身的真实会话、分片和文件断言。
