# M0 状态

本分支从空仓库的初始提交 `e583c3d` 开发。以下记录对应当前分支的 M0 实现。Actions 的按提交结果以运行页面为准。

| 能力 | 已实现范围 |
| --- | --- |
| 桌面 | Wails 3 窗口、内嵌 Vue 页面；连接、对象、任务、设置四个入口。本地连接支持保存、编辑、搜索及厂商筛选。对象浏览明确提示云适配器待接入。任务页读取 SQLite 中的真实记录。 |
| 语言 | 默认简体中文，内置英语；导入部分翻译并逐项回退。切换时复用同一窗口和服务。原生菜单、托盘和通知预留资源 key，尚无对应的自定义交互。 |
| 核心 | 连接公开配置、厂商能力、状态转换、应用级传输选项、带安全参数的错误。M0 关闭全部云端操作能力。 |
| SQLite | 首次迁移、版本检查、外键、WAL；保存连接、任务、上传会话、已确认分片与校验信息。写入冲突返回结构化错误。 |
| 构建 | 同一提交可通过原生 Windows amd64、Linux amd64、macOS arm64 和 amd64 工作流构建归档。配置见 [发布文档](RELEASING.md)。 |

## 验证记录

- **通过**：云端 Debian 13.7 x86_64，固定 Go 1.27.4。Docker 镜像安装 GTK 4.18.6、WebKitGTK 2.54.3 和原生 C 编译器。宿主 Node 24.22.3、npm 11.19.1。
- **通过**：锁文件安装、语言资源及占位符测试、导入和缺失翻译回退测试、Vue TypeScript 检查与生产构建。
- **通过**：独立核心与 SQLite 测试覆盖状态迁移、对象 Key 原样读回、分片重放与冲突、迁移失败回滚、数据库重开，以及子进程异常退出后的检查点读取。
- **待取证**：原生窗口交互、完整应用检查、GitHub 托管的四个构建和产物下载。编译不计入交互验收。
